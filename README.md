# Financial Health Assessment Tool for SMEs

A web-based financial analytics tool that helps Small and Medium Enterprises (SMEs) analyze their financial performance, assess business health, and receive intelligent recommendations.

This project was developed as part of a hackathon solution to provide actionable financial insights for businesses.

---

## 🚀 Features

- Upload financial CSV data
- Automated financial analysis
- Profit and expense calculations
- Business risk assessment
- AI-powered financial recommendations
- Business health score meter
- Loan eligibility prediction
- Revenue forecasting
- Interactive charts and visualizations
- User-friendly dashboard

---

## 📊 Dashboard Insights

The tool provides:

- Total Revenue
- Total Expenses
- Profit calculation
- Profit margin analysis
- Business risk level
- Loan eligibility status
- Business health score
- Revenue forecasting
- AI financial advice

Charts included:
- Revenue vs Expense comparison
- Expense vs Profit distribution
- Revenue forecast visualization

---

## 🛠 Tech Stack

Frontend:
- HTML, CSS, JavaScript

- Node.js + Express server

Backend:
- Python
